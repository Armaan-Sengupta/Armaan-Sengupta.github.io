LiDAR Point Clouds

Year 1 · Software · 2023

Filtering, voxel downsampling and a fast furthest-pair search on millions of points.

Processing a large urban LiDAR scan with laspy, Open3D and NumPy: voxel downsampling, a nearest-neighbour outlier filter for dust and artifacts, and a custom furthest-pair search fast enough for 1M+ points.

The project

Manipulating, cleaning and analyzing a massive LiDAR point cloud: removing anomalies, extracting buildings, and finding the two furthest points in a set of millions of points, a good excuse to try some fun algorithms.
