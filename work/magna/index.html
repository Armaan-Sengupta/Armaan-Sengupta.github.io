In-die crack detection

A real-time integrity monitor for an industrial hydraulic press, using strain gauges embedded near the die. I built the pipeline end to end: sensor data streamed over MQTT, re-synchronized and stored in PostgreSQL, plus a web dashboard where operators and engineers compare strain profiles across batches and review anomalies.

The detector

I designed an anomaly detection algorithm that finds the characteristic discontinuity in the strain signatures across four sensors when a part cracks during forming. Running in real time, it caught every cracked part with zero false positives over a 150-part validation run, removing defective parts from the line automatically. It recognizes when a different part is being stamped, and a moving-window average stops slow sensor drift from being flagged.

More data from the PLC

The press's PLC had very little memory. A patent-pending buffering system I engineered, with semaphore-driven multithreading and staged data queues, let it stream far more data, raising collection from about 140 Hz to over 500 Hz for much finer analysis of each stroke.
